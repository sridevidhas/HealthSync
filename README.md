# HealthSync – Multi-Role Clinical Workflow Platform

HealthSync is a full-stack clinical workflow platform designed to manage and streamline day-to-day operations across multiple clinical departments.

The system provides separate workflows for different user roles and integrates patient management, appointments, consultations, pharmacy, laboratory, and billing operations through a centralized platform.

## Features

- Patient management
- Appointment scheduling and management
- Doctor availability management
- Token generation
- Consultation management
- Pharmacy management
- Laboratory management
- Billing and payment management
- Role-based access control
- JWT-based authentication
- REST API integration
- CRUD operations
- Form validation and data management

## User Roles

The platform supports multiple user roles:

- Admin
- Doctor
- Receptionist
- Pharmacist
- Laboratory Technician

Each role has access to functionality relevant to its responsibilities.
